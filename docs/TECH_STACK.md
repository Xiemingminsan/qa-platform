# Technology Stack

## Backend
- FastAPI (Python) with Pydantic models
- SQLAlchemy ORM with PostgreSQL (hosted on Railway/Supabase)
- Auth via JWT bearer tokens
- Automatic API docs via Swagger/OpenAPI at `/docs`

## Frontend
- React 18 with TypeScript and Vite
- Styling with Tailwind CSS
- Routing with React Router
- API calls through Axios against the deployed backend

## Tooling
- GitHub for source control (public repo)
- Railway for backend hosting
- Vercel for frontend hosting
- pytest / npm test for automated checks
